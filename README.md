## About

Welcome to my personal blog hosted on GitHub Pages! This site is a fun space to share thoughts on life, doges, memes, Dogecoin, and my journey to becoming a full stack developer.

Much wow, such thoughts!

The blog includes:
- Real-time Dogecoin (DOGE) price updates.
- Posts on my Full Stack Developer (FSD) journey, tracking progress day by day.
- Reflections on the DOGE philosophy: "Do Only Good Everyday."

Visit the live site: [https://doge4lif3.github.io/](https://doge4lif3.github.io/)

## Features

- **Dogecoin Price Tracker**: Displays the current DOGE price with a loading indicator and last updated timestamp.
- **Blog Posts**: 
  - FSD Journey: Chronicles my 180-day path from beginner to pro, with updates like "Such code, much learning! day 55."
  - DOGE Section: Inspirational content, such as "Man is born for deeds of kindness."
- **Comments**: Each post has a "Show Comments" option for interaction.

The site is built with simple HTML, likely including JavaScript for dynamic elements like price fetching.

## Setup and Local Development

This is a static site powered by GitHub Pages. To run it locally:

1. Clone the repository:
   ```
   git clone https://github.com/doge4lif3/doge4lif3.github.io.git
   ```
2. Navigate to the project directory:
   ```
   cd doge4lif3.github.io
   ```
3. Open `index.html` in your browser, or use a local server (e.g., with Python):
   ```
   python -m http.server
   ```
   Then visit `http://localhost:8000` in your browser.

No additional dependencies are required, as it's a basic static site.
